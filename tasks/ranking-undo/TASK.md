**Review:** (Round 1, Nov 19, normal mode) **Ready.** No open defect.
- SG2 / SG2.3 criteria: line `Which one do you like more?` under the unchanged title: done (`en.ts`, `GameRanking.tsx`). `Undo` text button under the pair, same one step as Back, no extra tap on the happy path: done. Undo after a pick returns the same pair on the same sides; on the first pair goes to card 8 with 7 answers: done (session + screen tests). Undo in the 260 ms pause cancels the tap and keeps the pair: done. Binary insertion after an undo: done (the session test checks `game` is deeply equal to before the pick, then the Streetwear, Vintage sport, Outdoor result).
- `holdAnswer` use (`GameRanking.tsx` 35-50, unmount cleanup 24-27): sound. The hold is registered at tap and released in all three exits: Back/Undo (the cancel callback nulls `hold.current`, clears the timer, resets `dim` and `chosen`), the timer firing (`letGo()` before `pickInRanking`), and unmount (cleanup calls the release, which only clears `inFlight` if it is still this hold). `back()` in `styleGameSession.ts` takes the `inFlight` branch first, so the in-pause Undo never pops history. `startOver`/`endStyleGame` null `inFlight` and are not reachable from this stage. The screen is keyed on `rounds.length`, so a real pick remounts the component and the hold cannot leak into the next pair. Card 8's own hold (`GameCard.tsx` 109-148) is released on its exit, so it cannot make the first-pair Undo cancel the wrong thing.
- Tests: `npx jest` on the two T113 files: 72 passed. The in-pause test fails if the hold were missing (Back would pop to card 8 and `stage` would be `cards`), so it can fail. No `.only`/`.skip`, no test weakened (the old line test was retargeted to the new words).
