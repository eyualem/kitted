# T65 · The plain names of the rules

**These names await the founder's OK (Y24).** They are words users read: Kit says them when he explains a score ("the narrow leg is what's holding this back"). Nothing here is final until you say yes; T58 (the chat explanation) does not ship before. Edit any name in the third column's sentence or the second column, and the code table (`app/packages/kitted-core/src/ruleNames.ts`) follows.

How to read it: the plain name is a lowercase phrase Kit can drop mid-sentence. Rules for every name: at most five words, no digits, nothing about a face or a body, no emoji, no two the same. A few also have a known name, the trade's own word, which Kit can add when it helps ("the waist break, the rule of thirds"); those are marked. The example lines are only to show the name in use: the real explanation is written by the AI from the rule and the score, never copied from here.
