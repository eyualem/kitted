# T105 · Testing contract

Normal task: the session that builds it writes these tests (no separate test writer). The contract is the list below, one line per criterion ID on the plan line; a test never gets weaker to pass. Tests run on Jest in `app/` (`npx jest <file>`), with the memory store and the scripted-model harness in `app/src/testing/kitCardsHelpers.ts` (`harness`, `says`, `kit`, `rowOf`). Nothing calls a real model, nothing is paid (T110 does that).

**Plan-line IDs (11):** KC1.1, KC1.4, KC3.3, KC3.5, KC5.2, KC6.1, KC6.2, KC6.3, KC6.5, KC8.1, KC8.2. Each appears below.

**Test files** (new, under `app/src/__tests__/`): `kitWordsGate.test.ts` (the gate and the cut), `kitWordsPrompt.test.ts` (the map, the rules, the guide, the examples), `kitWordsPack.test.ts` (today's cards, the color list, the wiring through `createPrepare` and the pipeline). Test names start with the criterion ID: `KC1.1 · <what>`.

**Words:** this task shows no screen and adds no copy. The only lines Kit may say that come from the spec, word for word: `I rate outfits, never people.` (`t('ask.refuseFace')`), `I don't point to shops, but here's what to look for:`, `Ask me what to buy next, and I'll show it here.`. Nothing for the founder to approve.

## Fixtures
- **GATE** = a `GateContext` with `allowedScores: new Set()`; **COLORS** adds `allowedColors: new Set(['off_white_cream','light_blue','tan_camel'])`, `ownColors: new Set(['olive','black','denim_dark'])`.
- Thursday's closet from `kitCardsHelpers`: `tee` (White tee), `oliveSweater`, `jeans` (Dark jeans), `boots` (Black work boots), `bomber` (Tan bomber) via `rowOf`/`kit`; add a `Brown boots` row (`G('footwear','work_boot','brown')`) and `Khaki chinos` (`chinos`) where a case says so.
- **Today's cards:** stylist chat rows at `NOW` (2026-10-22 12:30 US Eastern) whose `payload.askCard` is the stored card, built by hand as plain objects (the shapes in `cards.ts`).
- The model's reply is scripted with `says(text, { card, followUps })`; a 70-word answer is 5 sentences of 14 words each.

## Edge cases from the spec's failure table that touch this task
- **The model proposes a color outside the list:** that sentence is dropped, the card is dropped if it holds the color (KC3.3 above).
- **Fewer than 2 options/colors pass:** no colors card, the words still answer (KC3.3 above).
- **A failure mid-way:** the color function failing returns an empty list (no colors card, no sentence rule); a corrupt stored card is skipped; the evidence builder never throws into `prepare` (a throw there would lose the whole question): wrap-test with a stand-in that throws.
- **Offline:** every rule here is local; the pack, map, list, gate and cut need no network (the tests run with none).
- **The 4 am day change:** today's cards use the 4 am day (KC6.3 above).
- **A wipe or a reinstall:** no chat rows, no closet: the pack has no cards block, the color list has `others = []`, the map is unchanged (it depends on the build, not on his data).
- **His closet is empty:** an `Example` card shows in today's cards as `(none of it his)`; color lists are all 24.
