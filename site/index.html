Kitted

Send an outfit photo, get a fit score out of 10 with one word for it, and the one fix that raises it. The app learns your closet as you go.

An iOS app for guys 18 to 30, built solo by Eyu Haile. The stylist is Kit, an AI persona; the score is computed by code, not by a model.

Read the code How it's built

How a fit check works

  • The AI sees. A vision model only describes the clothes: each piece, its color, fit and length.
  • The code judges. A deterministic scoring engine turns that description into the score, so the same photo always gets the same number.
  • The AI explains. The model only puts the code's verdict into words.
  • Privacy first. Faces are blurred on the phone before anything is sent; if the head can't be found, nothing is sent.

Under the hood

  • React Native and Expo (iOS first), TypeScript, Expo Router, SQLite on the phone.
  • The scoring engine was designed in Python, then ported to TypeScript; thousands of parity tests keep the two identical.
  • A Firebase server (Cloud Functions, Firestore) holds the AI keys, daily limits and a spend cap.
  • On-device face finding and blurring with Apple's Vision framework, in a native Swift module.
